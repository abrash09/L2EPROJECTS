Python Expense Tracker

A simple terminal application to record and analyze personal expenses, built with pure Python.

```
How to Run This Project
```
Follow these steps to run the Expense Tracker on your computer:
1. Install Python
If you don't have Python installed, download and install it from python.org.
2. Download the Code
Download this repository to your computer (either by cloning it or downloading the ZIP file and extracting it).
3. Open Your Terminal
Open your terminal (Command Prompt/PowerShell on Windows, or Terminal on Mac/Linux) and navigate to the folder where you saved the project.
4. Run the Application
Type the following command and press Enter:
python main.py
(Note: On some systems, you might need to type python3 main.py instead).
```
How to Use
Once the program starts, you will see a menu:
Enter 1 to add a new expense (you will be asked for the amount, category, and a short description).
Enter 2 to view all your previously recorded expenses.
Enter 3 to see the total sum of all your expenses.
Enter 4 to see your total spending broken down by category.
Enter 5 to delete a specific expense.
Enter 6 to save your expenses and exit the program.
Note: Your expenses are automatically saved in a file called expenses.json. The next time you run the program, your previous expenses will automatically be loaded back in!
```
